V1 WALL SENTENCE Persistence is also a replay horizon.

A slowly forgetting computation retains old events. If you stop updating it, those same old events must remain available to reconstruct where the computation should be now.

Claim boundary: v0 is an exact algebraic construction and v1 is a first-order state/replay experiment. This is not a biological-neuron claim, not evidence that arbitrary programs live in dendrites, and not a performance claim over mixture-of-experts or generic recurrent systems. Full replay is explicitly exact when complete history and switch latency are allowed. The checked-in Python receipts remain the scientific authority.
