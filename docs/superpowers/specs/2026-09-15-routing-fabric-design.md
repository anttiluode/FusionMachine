# FusionMachine v2 — routing fabric design

Date: 2026-09-15

## Purpose

v0 showed that preserving computational identity until a nonlinear boundary matters. v1 showed that persistent algorithmic state avoids replay at context switches. v2 adds the missing outward half of the machine:

> a rich resident dendritic computation crosses an AIS-like commit boundary as a low-dimensional event, while the axonal/synaptic material carries the route/address that determines which downstream dendritic computation is changed next.

The biological language is motivational. The scientific object is an asynchronous routed state machine whose event payload can be one bit because routing identity is embodied in the connection graph.

## Core decomposition

```text
resident dendritic state
        ↓
nonlinear soma / AIS commit gate
        ↓
1-bit event e ∈ {0,1}
        ↓
axon identity + branch graph + delay + synaptic weight
        ↓
local write into specific target dendritic compartments
        ↓
next resident computations
```

The code must keep these roles separate:

- **dendritic compartment** — owns rich local continuous state and local dynamics;
- **AIS gate** — decides whether the current resident computation becomes a public event, without rewriting the resident state;
- **axon route** — fixed/developed material map from source event identity to target dendritic addresses;
- **synapse** — local signed/gained write into a target compartment;
- **target dendrite** — interprets that write through its own dynamics.

## Scientific gates

### Gate 2A — address in matter

Construct several source cells that emit exactly the same binary pulse value `1`.

Each source has a distinct axonal route matrix. Verify that the same payload causes distinct, correct downstream dendritic update patterns solely because source/route identity differs.

Attackers:

1. **pooled-source attacker** — erase source/axon identity before routing; one bit remains but the destination becomes ambiguous;
2. **shuffled-route attacker** — preserve pulses but permute axonal route identity;
3. **digital-address oracle** — append an explicit source/address label to the pulse; this is a privileged control showing that missing route identity can be restored by adding payload information.

Primary claim if passed:

> Routing information need not be carried in event amplitude when the physical connection identity already supplies the address.

### Gate 2B — development: chemistry + activity

Start from a dense candidate graph between source axons and target dendritic compartments.

Each source and target receives:

- an imperfect fixed **chemical compatibility vector**;
- an activity trace generated by repeated source→target transition episodes.

A developmental score combines the two:

```text
score_ij = chemistry_ij + beta * activity_alignment_ij
```

and each source retains the top-k target branches.

Compare:

- chemistry only;
- activity only;
- chemistry + activity;
- random wiring;
- shuffled activity identities.

The benchmark is deliberately noisy: neither cue alone should be perfect. The combination must be frozen before evaluation, and held-out episodes must not change the graph.

Primary question:

> Can an imperfect identity prior and experienced co-activation jointly recover a more accurate transition graph than either source alone?

This is a computational analogue of developmental targeting plus activity-dependent refinement, not a literal molecular model.

### Gate 2C — AIS publication is not dendritic state

Drive a resident dendritic compartment continuously while an external gate suppresses AIS publication for a window.

Require:

- dendritic state continues to evolve during suppression;
- downstream targets receive no events during suppression;
- removing suppression immediately exposes the then-current resident state through the normal event rule.

This is the computational analogue of publication control. It must not reset or freeze the dendrite.

### Gate 2D — rerouting changes behavior without changing source computation

Freeze source dendritic trajectories and event times. Change only one axonal branch destination.

The downstream computation must change while source resident state and emitted pulse train remain bit-identical.

This is a causal fence against attributing routing behavior to the dendritic algorithm itself.

### Gate 2E — asynchronous chain

Compose multiple dendritic compartments into a small event-driven network. No global layer clock is allowed. Each compartment updates locally; AIS events schedule delayed writes through the route graph.

Demonstrate a deterministic multi-step computation whose path depends on route identity, with event logs exposing:

```text
source compartment
AIS event time
axon route / delay
target compartment
local target update
```

The goal is inspectability, not benchmark superiority.

## Model

A compartment `j` owns state `h_j(t)` and local input accumulator `u_j(t)`:

```text
h_j(t+1) = F_j(h_j(t), u_j(t))
```

A neuron groups one or more resident compartments and computes an event:

```text
e_i(t) = 1[ G_i(h_i(t), context_i(t)) > theta_i ]
```

The route graph applies the event without adding an address payload:

```text
u_j(t + d_ij) += W_ji * e_i(t)
```

The graph `(W, d)` therefore stores information that would otherwise have to travel with the pulse.

## Development model

The developmental gate uses synthetic latent route families. Each source has a chemical fingerprint `g_i`; each target has `q_j`; compatibility is a noisy similarity score. Activity alignment is computed only from a development split. The final graph is frozen and evaluated on held-out transition episodes.

The experiment must report graph-recovery accuracy and downstream routing accuracy separately. A successful behavioral score is not allowed to hide a poor recovered graph.

## Live site

The root Pages app becomes a three-generation laboratory:

- v0 — separated computations / nonlinear boundary;
- v1 — persistent resident state / replay horizon;
- **v2 — resident computation → AIS event → axonal routing → target dendrite.**

The v2 panel must visibly animate a one-bit pulse moving through source-specific wires. Controls:

- select source computation;
- toggle AIS suppression;
- choose learned / chemistry-only / activity-only / shuffled routes;
- reroute one branch;
- step or autoplay events.

The UI must display both the one-bit payload and the hidden route identity so users can see that the rich address is in the graph rather than the pulse.

## Biology / prior-art fence

The attached 2025 Neuron review by Fréal & Hoogenraad describes the AIS as a specialized compartment between somatodendritic and axonal domains, important for action-potential generation/modulation and neuronal polarity, and emphasizes that AIS structure is both stable and activity-plastic. It also describes AIS molecular heterogeneity, chandelier-cell axo-axonic innervation, and activity-dependent AIS remodeling.

FusionMachine v2 uses that literature only to motivate functional separation. It does **not** claim:

- that axons encode digital addresses;
- that dendrites are literally eigenmode programs;
- that chemical guidance is captured by one vector similarity;
- that chandelier cells implement software permissions;
- that the synthetic development rule reproduces neural development.

The computational question is narrower: what architecture results when rich local state, event publication, and material routing are treated as different variables?

## Success criteria

A strong v2 pass requires all of the following:

1. same one-bit pulse, different intact axon identities → correct distinct downstream targets;
2. pooling or shuffling route identity materially degrades routing;
3. chemistry+activity graph formation beats both chemistry-only and activity-only on held-out graph/routing metrics;
4. AIS suppression blocks publication without stopping resident-state evolution;
5. rerouting changes downstream behavior with bit-identical source state/event traces;
6. the asynchronous chain reproduces its frozen target trajectory without a layer clock;
7. all negative controls and privileged oracles remain visible in the receipt.

A failure on any scientific gate is recorded as a scientific failure, not tuned away.
